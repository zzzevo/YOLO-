⚙️ 参数调整（改完点右侧保存）

认错（把球认成别的）调高；漏检（没框）调低。默认 0.30
同一个球出现好几个框 → 调低；两个球挨着只框到一个 → 调高。默认 0.45
某一类老认错就单独调高它；老漏就单独调低
过滤远处小噪点误检（按上传帧像素算）。0 = 不过滤
专治地板/白线/阴影被框成球：球一定有饱和颜色且色块成团。 实测地板误检从 23% 降到 8%，真球召回只掉 1.8%。关掉它可排除"真球被误滤"
框内"饱和色"占比下限。调高 = 更严格（更容易滤掉暗淡的框）
色块"圆整度"下限。调高 = 更严格（只留接近圆的色块）
大 → 远处小球更准但更卡；小 → 更流畅。默认 640
服务器快就调高（更跟手），卡就调低
大 = 跟得更紧（略抖）；小 = 更顺滑（略拖
球被短暂挡住时框保留多久，避免一闪一闪
